Build agents that actually work.

A lean, reliable TypeScript framework for building LLM agents. Features native swarms, strict JSON outputs, tool approvals, and automatic retries out of the box.

$ npm install devsdk-core

Multi-Agent Swarms

Seamlessly transfer context between specialized agents. Throw a HandoffError and the Swarm orchestrator handles the rest—with strict loop prevention.

Strict Tool Guardrails

Need a human in the loop? Set requiresApproval: true on any tool, and block execution until explicitly approved.

Reliable by Default

Stop writing boilerplate for timeouts and rate limits. devsdk-core includes built-in exponential backoff and timeout handling for all LLM calls.

Structured Outputs

Define Zod schemas and enforce strict JSON responses natively. We handle the zodResponseFormat conversion under the hood.
