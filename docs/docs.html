Installation

devsdk-core requires Node.js 18+ and TypeScript 5.0+.

npm install devsdk-core openai zod

Quick Start

Create an agent and execute a task in a few lines of code.

import { Agent, OpenAIProvider } from "devsdk-core";

const provider = new OpenAIProvider({ apiKey: process.env.OPENAI_API_KEY });

const agent = new Agent({
  name: "HelperBot",
  instructions: "You are a helpful assistant.",
  provider
});

async function main() {
  const result = await agent.run("Say hello!");
  console.log(result);
}
main();

Tools

Tools allow your agents to interact with the outside world. We use Zod to strictly validate tool arguments.

import { createTool } from "devsdk-core";
import { z } from "zod";

const getWeather = createTool(
  "get_weather",
  "Get the current weather",
  z.object({ location: z.string() }),
  async ({ location }) => ({ temp: 72, condition: "Sunny", location })
);

Swarms & Handoffs

Build multi-agent swarms by allowing agents to transfer context to each other using HandoffError.

import { Swarm, HandoffError } from "devsdk-core";

const escalateTool = createTool(
  "escalate", 
  "Transfer to support", 
  z.object({ reason: z.string() }),
  async ({ reason }) => { throw new HandoffError(supportAgentConfig, reason); }
);

const swarm = new Swarm(triageAgent, 3); // Max 3 handoffs to prevent loops
await swarm.run("My computer is broken!");

Guardrails & Approvals

Implement human-in-the-loop approvals for dangerous tools by setting requiresApproval: true on your Tool, and providing an approveTool callback.

const agent = new Agent({
  // ...
  approveTool: async (toolName, args) => {
    console.log(`Approve execution of ${toolName}?`, args);
    return true; // Return false to throw an ApprovalError
  }
});

Memory & Sessions

Persist conversation history natively using the provided memory adapters.

import { FileAdapter, InMemoryAdapter } from "devsdk-core";

// Persists to a local JSON file
const memory = new FileAdapter("./memory.json");
const agent = new Agent({ provider, memory });

Structured Outputs

Force the LLM to return valid JSON matching your schema.

const agent = new Agent({
  // ...
  responseSchema: z.object({ 
    summary: z.string(),
    sentiment: z.enum(["positive", "negative"])
  })
});
// result will be guaranteed to parse as the schema above.

Streaming & Tracing

Subscribe to granular events to trace execution, stream text, and log tool usage.

agent.onEvent((event) => {
  if (event.type === "tool_started") {
    console.log(`Running: ${event.data.tool}`);
  }
});

Error Handling & Reliability

devsdk-core automatically handles timeouts and exponential backoff retries.

const agent = new Agent({
  // ...
  maxRetries: 3,
  timeoutMs: 15000 // 15 seconds
});
